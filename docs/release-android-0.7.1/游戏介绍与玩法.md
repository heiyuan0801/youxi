# 晴野物语

**种一片田，养一群小伙伴，把日子过成喜欢的模样。**

《晴野物语》是一款温暖轻松的横屏农场经营游戏。播种收获、照顾动物，把原材料加工成美味商品；用订单赚来的金币扩建农场，装扮自己的小屋，再带上伙伴去森林、矿山、海滩和雪原探索。晴雨流转、四季更替，每次回家，都能看见农场又长大了一点。

## 游戏亮点

- **田间收获**：22种作物逐步解锁，点按或划动连续种植、收获，浇水可缩短生长时间。
- **动物相伴**：27种陆地动物与5种水产，照料、互动、外出游玩、训练和友谊赛；稀有品种等待发现。
- **基因育种**：选择同族双亲，定向培育产能、温顺或体质，迎接带有父母基因的新伙伴。
- **加工经营**：9类工厂、26份配方，从小麦到面粉再到面包，完成订单或出售产品，积累升级资金。
- **世界探索**：主农场与5处旅行目的地，4个资源区域可逐层深入，选择路线、处理奇遇、带回材料。
- **自由小屋**：家具可以自由摆放、拖动、旋转，同款可买多件；更换墙地颜色，把小屋扩得更宽敞。
- **四季生活**：季节与天气影响农场，参与当季交货活动，寻找极光带来的稀有机会。
- **离线经营**：解锁管理站后，最多结算8小时自动生产；收获、补种、喂养与加工按实际材料持续进行。

## 新手先做什么

1. **先收菜**：点成熟作物收获。收获进入仓库，并获得经验。
2. **再播种**：点空地打开种子选择器，先种生长快、价格低的小麦；选择种子后可划过空地连续播种。
3. **照顾伙伴**：点击鸡、牛可听到叫声，产物成熟后点击领取。在“动物伙伴”里喂食、互动和治疗。
4. **完成订单**：查看底部“订单”需要的物品，凑齐后交付换金币和经验；仓库也能出售多余物品。
5. **领取升级奖励**：升级会出现星星奖励卡，点击“太棒了！”领取。点左上等级或“等级册”可查看奖励和解锁。
6. **扩大经营**：在“开拓地图”解锁草甸、果林和牧场；新区还要逐块开垦。通过工坊加工，提高原材料价值。

## 动物养成与育种

饱食、心情、健康、亲密度、成长等级和基因会影响动物表现。先喂好、照顾好，再培育、训练与参赛。

定向育种须两位同族伙伴成年、亲密≥20、心情≥60，且不在繁殖冷却。消耗150金币和6饲料，2分钟后接回幼崽；接回后还需5分钟长大。双亲冷却1小时。自身、亲子、共享父母的兄弟姐妹不能配对。

产能基因提高下一轮生产效率，温顺有利于互动亲密，体质减缓饥饿。基因、双亲和代数会保存；刷新不能重抽幼崽。普通与稀有同族可以配对，例如奶牛和彩虹牛、绵羊和黄金羊。

## 探索、装修与自动化

**探索**：森林、矿山、海滩、雪原各最多12层，每层推进3次。出发花4农场体力，探索有独立体力。可采集、扎营，或帮忙修桥、照顾幼鸟；成年伙伴可同行。随时安全返程，背包入库；每层首次完成另得80金币、2农场星。等级与体力决定能否深入。

**装修**：家具可自由移动、旋转、收回，地毯能和家具搭配；其他家具之间需留距离。最多拥有40件家具，支持重复购买。房间6×6→8×8花800金币、3木板；8×8→10×10花1600金币、5木板。墙面和地板各有4种配色。

**自动化**：10级花800金币、10木材、5铜矿建管理站。收菜器和喂养器需另建并开启。自动补种会扣种子费，喂养和水产循环会扣饲料，加工会扣实际配方原料；每厂可选一种自动配方。缺料暂停对应任务，不会免费生成材料。离线最多结算8小时，回来可查看收获、支出和库存净变化。
