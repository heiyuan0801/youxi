# TestFlight 可填写文案

## Beta App Description

欢迎来到《晴野物语》！在这座温暖的小农场里，播种收获、照顾动物、经营工坊，把一片田园慢慢变成自己的理想家园。还能培育动物品种、自由布置小屋，带着伙伴走进森林、矿山和海岸，发现新的风景与资源。

游戏采用横屏操作，主要玩法支持单机离线。本测试版无需账号、没有广告或内购，进度保存在当前设备。自动农场最多结算 8 小时离线收益。本版暂不支持云存档、游戏内存档导入、真实玩家交易或多人合作。

## What to Test

请重点测试以下内容：

1. iPhone / iPad 左右横屏时，等级、货币、底栏和弹窗是否遮挡，点击是否准确。
2. 种植、收菜、喂养、生产、订单与升级奖励是否正确结算。
3. 点击鸡和牛的音效、音乐开关、振动开关及静音行为。
4. 旅行场景的返回入口、育种、小屋家具拖拽和分层探索。
5. 切换后台、锁屏、重启后是否保留进度，离线收益是否只领取一次。
6. “设置 → 导出存档”能否保存有效 JSON，取消时是否正常返回。
7. 飞行模式下冷启动和主要玩法是否正常。

如遇问题，请通过 TestFlight“发送 Beta 反馈”提供机型、iOS 版本、操作步骤和截图。请勿在反馈或导出文件中附带密码等敏感信息。

## Beta App Review Notes

这是单机休闲农场游戏，不需要登录，也没有账号、内购或广告。点击“开始游戏”即可进入，先点击成熟麦田收获，再点击空地选择种子。右上角齿轮进入设置，可调整声音和触感、导出本机存档并阅读隐私说明。游戏资源已随应用打包，核心玩法无需网络。部分内容随着游戏等级逐步解锁。

测试安装与反馈使用 Apple TestFlight；游戏自身不提供用户交流、真实交易或多人服务。
