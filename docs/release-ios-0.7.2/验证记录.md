浏览器测试不等于 iOS 原生测试。安全区数值测试使用明确的 UIKit inset 样例；原生存档文件选择器、触感、音频静音、前后台行为与真实设备触摸仍在真机验收清单内。

本机起初没有 iOS 模拟器运行时；Cocos 3.8.7 的随附模拟器依赖为 x86_64，不能直接用于 ARM64 模拟器，因此停止了不匹配的运行时下载。没有把模拟器安装或“编译成功”当作原生游玩验收。

## 可复现入口

- `npm test`
- `npm run typecheck`
- 启动 `npm run serve` 后执行 `npm run smoke`、`npm run smoke:advanced`、`node tools/smoke-ios-layout.mjs`
- `npm run build:ios`、`npm run package:ios`
- `python3 tools/verify-ios.py`

本机原始日志位于 `artifacts/ios-0.7.2/`；交付包包含验证 JSON 与代表性界面截图。未签名归档中没有 `_CodeSignature` 或 `embedded.mobileprovision`。包文件大小与 SHA-256 见发布 manifest。
