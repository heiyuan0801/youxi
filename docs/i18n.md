# 多语言

玩家在「设置 → 语言」里切换。选项会写进本地存档，下次打开仍用这个语言。新农场第一次建立时，会看设备语言：简体中文、繁体中文、英文、日文、韩文。认不出来就用简体中文。旧存档没有语言字段时，也保持简体中文。

界面文案在 `assets/scripts/Locale.ts`。`t('hud.plant')` 取当前语言；该语言没有这条时，用简体中文；简体也没有时，把键名原样显示。作物名、地图名可以用 `tx('crop.wheat', '小麦')`，没有译文就显示原来的中文名字。

加一种语言：在 `LOCALES` 里加上代码，补一份和 `zh-CN` 相同键的翻译，并在设置按钮的 `LOCALE_LABEL` 写上名字。长篇探索故事、订单对白还没有逐句翻译，那些句子继续显示简体中文。
