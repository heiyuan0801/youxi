# 晴野农场 · 0.5.0

Cocos Creator 3.8.7 + TypeScript 横屏农场，扩展至 **22种作物、14种动物、100级、9类工厂、26份配方、65种产品、6张地图**。主农场保留三个相邻扩张区域，最终84个田位。

[本机试玩](http://localhost:7526/?v=0.5.0) · [六阶段路线](docs/expansion/v05/roadmap.md) · [内容数值](docs/expansion/v05/content.md) · [验收](docs/verification.md)

## 本版玩法

- 种子选择器4页，新增水稻、土豆、卷心菜、黄瓜、大豆、棉花、甘蔗、西瓜、葡萄、橙子、油葵、可可、咖啡、薰衣草、极光莓和黄金南瓜，逐级解锁。
- 鸡、牛、鸭、羊、猪、山羊、兔、猫、狗、马、孔雀、黄金羊、彩虹牛、独角兽各有产物。新增动物实际移动、转向、起伏和回应点击；原鸡牛完整动作帧保留。猪找松露，猫巡逻带回香草，狗增加探索奖励，马／独角兽缩短探索时间。
- “动物伙伴”可喂食、互动、治疗。饱食、心情、健康、亲密和稀有度影响下一轮效率。两只同品种成年动物亲密≥20、心情≥60，花100金币及4饲料可繁殖；育幼2分钟、成长5分钟、双亲冷却1小时。羊／牛有5%稀有变种概率，结果开始时保存。离线饥饿有下限，不会离线死亡。
- 九类工厂：磨坊、面包房、奶制品厂、果汁厂、纺织厂、糖果厂、酿造坊、木材厂、罐头厂。各厂独立队列，同厂顺序加工，基础每厂2格，升级至5格。小麦→面粉→面包，棉花→棉布→衣服，木材→木板→家具，甘蔗→糖→糖果／巧克力等使用真实材料；旧配方及活跃时间保留。
- “旅行手册”前往工匠小镇、青杉森林、蓝晶矿山、贝壳海滩、极光雪原。小镇建筑可进入对应工厂；资源地图各9个节点，耗2体力、10分钟恢复。体力上限24、每2分钟恢复1。远行耗4体力、基础30秒，奖励和倒计时保存，离线继续；海滩码头可钓鱼。
- 每20分钟换季、4分钟换天气。右上季节入口有当季目标，春花会／夏渔赛／秋丰收／冬工匠。雨、暴雨、雷雨自动浇水一次；大雪暂停咖啡、可可、西瓜、黄瓜、甘蔗。雷电送铜矿，彩虹送宝石，极光送极光莓并提前解锁种子，每天气时段只领一次；不做离线毁田。
- “我的小屋”购买7种家具，消耗金币、木板、棉布，选中后摆入6个位置，可移动，刷新保存。
- 四季面板建造自动收获器（10级、400金币、5铜矿）和自动喂养器（6级、250金币、2铜矿），单独开关。游戏打开、主农场、无弹窗或手势时每5秒检查；喂养只消耗已有饲料，没有离线自动循环或自动补种。
- 100级奖励册保留用户参考图的大星星、新解锁卡片及“太棒了！”按钮。每级只领一次，可补领旧等级；满级经验条保持满格。扩充高等级加工／稀有农产品订单。

## 原有操作

点成熟作物收获、点空地选种，选种后划过空地连续播种，划过成熟田地连续收获。再次点同一生长作物浇水一次，缩短20%生长时间。拖动地图、滚轮／双指／右上加减缩放；Esc关闭弹窗或取消操作。

底部农场／仓库／订单／商店保留，商店有土地、动物、装饰、农场星。原村民行走、坐凳聊天，汽车／货车行驶，交货触发货车出发。每日5选3目标、三级设施、图鉴奖励、18格花圃、普通及特别装饰继续可用。“开拓地图”3／6／10级开放草甸、果林、牧场；新区独立开垦，苹果树／蜂箱和礼篮配方保留。鸡叫、牛叫、收菜、升级音效及开关保留。

## 编辑、构建与检查

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run serve
# 启动服务后
npm run smoke
npm run smoke:features
npm run smoke:progression
node tools/smoke-level-batch.mjs
npm run smoke:life
```

Cocos Dashboard添加本目录，用 **Creator 3.8.7** 打开 `assets/scenes/Farm.scene`。H5输出 `build/web-desktop`，通过HTTP访问。默认引擎路径 `/Volumes/mac/tools/cocos/3.8.7/CocosCreator.app/Contents/MacOS/CocosCreator`，可用 `COCOS_CREATOR` 修改；其他机器需修改 `tsconfig.check.json` 引擎声明路径。3.8.8本机导入不稳定，本版固定3.8.7。浏览器测试使用独立存档和外置盘Chromium，可用 `CHROME_PATH` 修改。

## 工程与保存

`FarmCatalog`保存新内容配置，`FarmLife`负责照料、繁殖、旅行、体力、探险、四季、家园和自动化，`LifePanels`绘制原生界面。`FarmModel`管理基本经济和迁移；`FarmFeatures`管理加工、钓鱼、每日、设施、图鉴；`FarmProgression`管理等级和农场扩张。场景、运动、输入、音效模块继续保留。

运行美术共183张，新81张在 `assets/resources/lifeart`，透明图集、完整提示词、处理脚本和校验值见 [素材记录](docs/expansion/v05/art.md)。新增动物采用独立精灵加运行时运动，没有为每种新动物制作多帧逐帧动画。音效来源见 `docs/audio/CREDITS.md`。原站公开前端快照保留在 `reference-site`，不是未发布的原工程或服务端；运行不依赖原站。0.4文档保存在 `docs/history/v04`。

存档键仍为 `sunny-meadow-farm-v1`，0.4先备份原始JSON至 `-before-v05` 再迁移，保留余额、库存、地块、动物、装饰、订单和既有生产时间。无效存档也先备份。设置可导出JSON，重置前确认并备份。

剩余动物、水产养殖、完整基因谱系、动物比赛、真实日期节日和社交／交易／合作社／排行榜在路线中标明后续。本版为本地H5／Cocos工程，未进行真机、TapTap／微信容器或联网服务验收。
