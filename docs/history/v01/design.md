# 晴野农场 0.1.0

横屏、中文、轻松种植经营。参考游戏的斜视地图、田地操作和经营面板，使用原创生成素材，不包含语言学习。

- 引擎：Cocos Creator 3.8.7，TypeScript；参考画布1600×900，等比适配并保留完整HUD。本机3.8.8命令行导入不稳定，最终固定为已完成实际构建验证的3.8.7。
- 视角：2D斜视菱形地块，手绘卡通建筑和作物；光从左上方照入。
- 主循环：播种→浇水（可选，一次缩短20%）→成熟收获→出售/订单→经验升级→扩地、养殖、装饰。
- 内容：30块田（初始12块）、6种作物、鸡/牛、8种产品、5类循环订单、6个成长任务、2种可摆放树木。
- 鼠标/触摸：点空地播种，点成熟作物收获；从空田开始划动连续播种；从道路/已有作物开始拖动画面；缩放按钮和鼠标滚轮。
- 仓库、订单、商店、任务为原生Cocos UI，面板阻挡地图操作；Esc关闭面板。
- 存档：版本化JSON；只存模拟状态，不存Cocos节点。实际时间戳使作物离线成熟。动物最多存一份待收产物，不累计无限离线产品。存档无效时保留原始备份再开新农场。
- 自动本地保存；设置页支持导出JSON备份。此版无云端同步、支付或联网多人。
- 结构：FarmModel负责纯模拟/计时/经济/存档校验；FarmApp负责场景、输入、UI、音效和本地适配；PNG资源从resources加载。

## 美术规范

暖白、嫩绿、麦金、陶橘色。圆润体块、细棕色描边；构图与视角统一。主体建筑384×384，作物和动物192×192，底部居中锚点，真实alpha透明。运行时播放六帧小鸡PNG；GIF供审核预览。风车叶片为独立几何图形实时转动，文字与UI用引擎绘制。

生成工具：本会话内置image_gen。工具不提供模型版本选择，未将结果标记为特定“2.6”模型输出。源图、切图规则与GIF保存在docs/art；art/asset-manifest.json记录实际尺寸、来源与锚点。

生成提示：一张严格4×4、16个透明精灵的原创斜视农场素材图，依次为农舍、谷仓、无叶片风车、鸡舍、集市摊位、绿树、樱花树、池塘、小麦、胡萝卜、草莓、番茄、玉米、南瓜、母鸡、奶牛。温暖手绘卡通、细棕色轮廓、统一左上光照，不含文字。随后以此图为风格和角色参考，生成严格3×2的六帧母鸡眨眼/低头待机图，统一大小、脚底基线和alpha透明。

## 验收

模型测试覆盖经济扣款与防重复领取、成熟时间与浇水、订单原子交付、扩地上限、动物冷却、任务、离线与坏档校验；另以真实Cocos构建在浏览器点击试玩，检查控制台与多个横屏尺寸。硬件与平台容器验收需另行进行。
