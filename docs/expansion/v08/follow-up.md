# 0.8 玩法加深 · 已接线与待换美术

这一轮把主线、酿造、探索、比赛和自动化从“能结算”补到“能接着玩”。下面这些位置已经接进存档和界面，专用图还用现有物件顶着，换图时只改资源，不必改规则。

## 酿造

酿造工坊在果醋之外增加四条作物链：

| 配方 | 原料 | 占位图标 |
| --- | --- | --- |
| 手冲咖啡 | 咖啡 ×2 | `coffee` |
| 葵花凉茶 | 油葵 ×2 + 香草 ×1 | `sunflowerCrop` |
| 薰衣草花茶 | 薰衣草 ×2 + 香草 ×1 | `lavender` |
| 极光莓茶 | 极光莓 ×1 + 香草 ×1 | `auroraBerry` |

占位表在 `FarmCatalog.ART_PLACEHOLDERS`。加载完成后，如果还没有同名贴图，就复用对应作物图。以后把正式图标放进资源加载列表，并删掉对应别名即可。

## 探索层美术位

森林、矿山、海滩、雪原各 12 层。层号对应 `levelTheme(map, depth)`：

- `art` / `id`：`forest-layer-01` … `forest-layer-12`，矿山、海滩、雪原同样。
- 画面现在用三档地色加深浅变化，地标仍是现有树、矿石、码头、冰晶图标。
- 第 3、6、9 层是当地奇遇（林狐、晶脉、海贝、极光裂隙）。林狐暂时用小狗图标。
- 第 4、8、12 层是地图谜题。提示写在面板上，选错扣 1 点探索体力，不推进路线。

换层美术时，按 `art` 名字出图，并在 `FarmScene.drawTravel` 里把 `theme.icon` 换成新图键。

## 动物音效

陆地动物的点击音仍是原来的 27 条，猫抓鼠、狗寻物和池塘总溅水也没改。

五种水产以前点下去都只播同一段 `pondSplash`。现在各自有一条音效，键名和水产 id 相同：`carp`、`crucian`、`bass`、`crab`、`lobster`。这五条是用现有 CC0 溅水剪出来的音高和节拍，螃蟹和龙虾加了短促的螯击。换成正式录音时，覆盖 `assets/resources/audio/` 里同名 wav 即可，不用改 `AnimalVoices.ts`。

`bird.wav` 仍在资源目录里，但没有动物引用它。鹅、火鸡、鹌鹑、鸽子、孔雀都已经有自己的音效，所以没有把这段鸟叫盖上去。以后如果要给某只鸟换录音，可以用它替换对应 wav。

## 设备动画

自动收获器和自动喂养器建成后画在田边小路和动物区路口。开启时轮子和摇臂会动，有活干时转得更快。图形是代码绘制的，不是新贴图。若要换成正式机器图，保留 `machinePose` 的 `spin` / `arm` / `bob`，把 `FarmScene.drawMachines` 里的椭圆改成精灵即可。
