# 0.4.0 规划：有声音、有升级反馈、可扩张的农场

保留现有 Cocos Creator 3.8.7 横屏农场。先建立“经营获得经验 → 等级奖励与新解锁 → 开拓地图 → 新区域生产 → 高价值订单”的循环。本文件先于实现写入，以下区分本版工作和后续方向。

## 本版实施

### 声音与反馈

- 点击母鸡播放真实鸡叫，点击奶牛播放真实牛叫，是否有产物都可以触发。
- 收菜播放短促的采摘／入篮音效，划动连收可连续触发，限制播放频率以避免叠加刺耳。
- 升级播放庆祝音效，沿用现有音效与音乐开关。动物样本取自标明 CC0 的作者原站，记录来源；收获和升级音效自行合成并随包提供。

### 等级奖励

- 按用户提供的图片制作：中央大金星、等级数字、放射光芒、暖白圆角卡片、橙色升级标题、新解锁图标、绿色“太棒了！”按钮。
- 每级奖励为 `40+20×等级` 金币、`1+floor(等级/5)` 农场星；每三级额外 2 份鱼饵。2—50级各可领取一次。
- 升级自动展示弹窗，跨多级依次展示；左上等级星可以查看等级册和补领未领的旧等级奖励。进入旧存档时不连续弹出历史奖励。
- 解锁内容来自实际作物、动物、配方、装饰和地图区域数据。5级显示奶牛和石井，和参考图一致。

### 新区域生产

- 苹果树每120秒产一份苹果，蜂箱每180秒产一份蜂蜜，离线计时，最多各保留一份待收产物。
- 工坊新增果园礼篮：2苹果、1蜂蜜、1面包，120秒，售价330金币；6级可制作，需要先开拓果林获得原料。
- 新产品进入仓库、图鉴和按等级开放的订单；图鉴旧奖励保持不变，并追加全收集奖励。

## 存档和验证

沿用原存档键，新增独立 progression.schema=1。迁移前备份原始JSON，旧金币、经验、田地、动物、工坊、每日目标、图鉴不清空。新区域田地只在开拓时追加。验证模型原子扣款、奖励防重领、区域顺序、离线生产、旧档迁移，及真实浏览器的音频触发、升级弹窗、新区操作和手机横屏。

## 后续版本方向（不计入本版已完成内容）

1. **天气与季节**：短周期晴雨、雨天自动浇水、季节作物；先让天气影响策略，再增加纯装饰天气效果。
2. **动物成长**：幼崽到成年、好感度和喂养、产物品质；照料提供加成，不惩罚短期离线玩家。
3. **农场布置**：装饰移动／回收、道路编辑、区域命名、截图模式；保存摆放数据并保留撤销。
4. **丰收活动**：周末集市、限时合作订单、节庆配方和收藏；基础经营内容保持随时可玩。
5. **长期目标**：农场声望、建筑外观升级、区域专精、更多加工链；云存档和好友访问在本地玩法稳定后再接入。
