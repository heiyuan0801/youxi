# 六阶段路线与0.5.0实施清单

本路线依据用户提供的六阶段、动物分类、生产链、天气季节和社交清单整理。沿用Cocos Creator 3.8.7横屏工程，已有存档和0.4.0升级卡样式保留。

| 阶段 | 内容 | 交付方式 |
|---|---|---|
| 1 基础农场 | 种植、收获、养殖、田地、音效 | 已有基础，本版增加内容与照料 |
| 2 经营成长 | 作物、加工工厂、订单、等级 | 本版扩到22种作物、14种动物、9类工厂、100级 |
| 3 世界探索 | 多地图、钓鱼、挖矿、探索 | 本版加入森林、矿山、海滩、雪地、工匠小镇；资源与生产链互通 |
| 4 家园四季 | 装修、天气、季节、节日 | 本版做家具摆放、四季、天气、季节目标；真实日历节庆和灾害保险继续扩展 |
| 5 生态与效率 | 稀有动物、杂交、宠物、自动化 | 本版做动物照料／配对／幼崽／稀有品种、宠物探索作用、自动收菜和喂养；基因谱系、比赛继续扩展 |
| 6 社交运营 | 互访、礼物、交易、合作社、排行榜 | 需要真实账号、服务器和权威账本，先定义服务契约，不用本地假数据冒充联网 |

## 本版内容

- 作物：原6种，加水稻、土豆、卷心菜、黄瓜、大豆、棉花、甘蔗、可可、咖啡、西瓜、葡萄、橙子、油葵、薰衣草、极光莓、黄金南瓜。
- 动物：鸡、牛、鸭、羊、猪、山羊、兔、猫、狗、马、孔雀、黄金羊、彩虹牛、独角兽。
- 属性：饥饿、心情、健康、亲密、成长、稀有度、效率。旧鸡牛起始效率保持1，避免改变旧档冷却。离线饥饿有下限，不因长时间离线死亡。
- 繁殖：两只成年同品种动物、亲密门槛、饲料费用和冷却；孕育后接回幼崽，再成长为可生产的成年动物；羊／牛有稀有品种概率。
- 工厂：磨坊、面包房、奶制品厂、果汁厂、纺织厂、糖果厂、酿造坊、木材厂、罐头厂。各厂独立排队；原有配方和正在加工的任务保留，新增“小麦→面粉→面包”等生产路线。
- 世界：主农场保留三片扩张区域；新增独立旅行地图，矿石、木材、草药、宝石、冰晶进入仓库与配方。
- 天气：晴、雨、暴雨、雷雨、雪、彩虹、极光。雨水自动浇灌；雪暂停敏感作物；彩虹／极光有可领取的事件奖励。本版暴雨仅浇水和视觉变化，不造成任何农田损失；灾害损失、保险与动物疾病继续扩展，不因离线死亡。
- 季节：每20分钟一季，四季轮换，每季有不同目标；之后可接真实日期节日。
- 家园：家具购买、拥有和位置保存，原生界面预览房间。
- 自动化：可购买并开关自动收菜和自动喂养，材料不足时不透支；自动收菜在停留农场时工作。

## 社交服务契约

账号与存档使用服务器玩家ID、版本号和幂等请求ID；余额、库存、订单、交易由服务器校验并事务结算。本地存档不作为线上交易的可信账本。

1. 好友／互访：公开农场快照，拜访令牌，访问与互动限额。
2. 赠礼：每日额度，赠送／领取状态机，幂等领取，反重复发货。
3. 市场：挂单、预占库存、成交、撤单、税费、到期；服务器事务与审计。
4. 合作社：成员／权限、贡献、大订单分工、退出后的收益结算。
5. 排行榜：服务器成绩与赛季快照，区分经营、装饰、合作贡献，不接受任意客户端分数。
6. 租地与联合工厂：租期、权限、产物归属、退款／解约规则；依赖前五项稳定后实施。

以上联网能力不计入0.5.0本地版完成数。后续先选部署和账号方案，再做双客户端及断线、重复请求、交易回滚验收。
