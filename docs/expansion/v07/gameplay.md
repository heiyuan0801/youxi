# 晴野物语 0.7.0 · 新玩法

## 基因育种

入口：动物伙伴 → 基因育种 → 选择两位双亲 → 选择偏重属性 → 定向培育。

每只动物拥有产能、温顺、体质三组双等位基因和父母谱系。新购买动物有固定的初始差异；旧动物以中性基因迁移，已有生产计时保持。普通牛／彩虹牛、羊／黄金羊、孔雀／白色孔雀、马／独角兽分别属于同族，其余按物种配对。

双亲须成年、亲密至少20、心情至少60，且繁殖冷却结束。不可自身、亲子或同亲兄弟姐妹配对。花150金币、6饲料，育幼2分钟；双亲冷却1小时。最多3个育幼任务、总动物与幼崽合计不超过60只。幼崽接回后5分钟成年。

定向属性从双方各取较强等位基因，其他属性各继承一个。每组有2%突变机会，基因上限3。结果在开始育幼时固定，刷新不能重抽。产能增加下一轮效率；温顺增加互动亲密；体质减慢饥饿。旧100金币、4饲料繁殖入口保留，也记录继承结果。

当前为简化的三性状玩法：没有性别系统或复杂显隐性遗传，近亲限制覆盖自身、亲子与共享父母，未覆盖整个远亲家谱。

## 自由装修

入口：我的小屋。拖动房间里的家具直接移动；也可在列表选中家具，再点地板放置。点击家具选中后，可旋转90°或收回家具箱。家具位置使用连续坐标，地毯可与其他家具叠放，其他家具不能过近。摆放越界或冲突时恢复原位置。

7种家具可重复购买，最多40件。可循环切换4种墙面、4种地板颜色。扩房6×6→8×8需800金币、3木板；8×8→10×10需1600金币、5木板。所有位置、角度、墙地配色和扩房状态保存。旧六位置自动对应到新房间位置，不重新收费。

当前是2D家具图像旋转和颜色装修，没有增加每件家具的四方向独立美术或墙面材质。

## 深度探索

入口：旅行手册 → 前往森林／矿山／海滩／雪原 → 旅行手册 → 分层探索。

每个区域最多12层，每层推进3次；出发消耗4农场体力，获得12探索体力。可带任意成年陆地动物同行。马、独角兽、骆驼使路线消耗降为1；狗使采集产量增加1。

采集通常消耗2探索体力；事件入口消耗1。断桥需要1木板、幼鸟需要1饲料、清泉需要1香草，帮助后获得1宝石与2体力；也可花1体力绕行，得1木材。扎营消耗1饲料恢复5体力，不推进路线。矿山产矿物，雪原采集路线为冰湖垂钓，其他地区按本地资源产出。

下一层需要1探索体力，等级门槛为地图基础解锁等级＋当前层数×3。资源暂存探索背包，返程后入库并获得经验；每层首次完成额外80金币和2星。重复通层可采资源，但不重复领首次奖励。第4、8、12层的谜题第一次解开会把一件家具放进家具箱，同一层不会再送。每一层有一句短故事；第6层之后的事件会多一句当地的后续。途中返程也可带回已获得物资。地图、路线、事件与背包刷新后保留。

冰湖另有控线：在雪原，或冬季的主农场打开冰湖面板，花1份鱼饵稳住4次越来越窄的绿色区。4次全中是金色锦鲤，3次是溪流鱼。分数记入今日、本周和个人最好。

常驻“返回主农场”先回家、保留未完成探索；要结算背包，打开“分层探索”点“安全返程 · 物资入库”。当前是地图节点与分支事件玩法，没有战斗、副本角色自由行走或新地形关卡美术。

## 离线自动化

入口：右侧自动农场。10级花800金币、10木材、5铜矿建立管理站。收菜器、喂养器仍需分别建造并开启。选项可单独设置：自动补种、动物产物、水产循环、加工循环。

- 自动补种需收菜器开启，选择已解锁种子；每次扣正式种子价格。
- 动物产物遵循成年、生产周期和照料规则；喂养器只用现有饲料。
- 水产循环只处理已建池：成熟领取、消耗饲料启动下一轮。
- 加工需已建工厂、已解锁配方。每厂选一个自动配方，按队列容量和实际材料接续；上游产出可供下游使用。
- 缺钱、缺饲料、缺材料时暂停相应任务，其他可执行任务继续。没有自动卖货或免费补材料。

在线与离线使用同一套每5秒检查的规则；退出页面记录结算时点，再次打开按时间顺序补算。最长8小时，多出时段不再重复补算。报告显示次数、支出、经验和仓库净变化。产物已入库、材料已扣除，确认报告只关窗口，重复查看不重复领奖。

旧档默认未建管理站。暂停后不追溯该时段；使用本机时间和本地存档，适合单机，没有服务器校时与多设备冲突合并。
