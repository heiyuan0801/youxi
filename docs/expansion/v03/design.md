# 0.3.0 经营扩展

保留现有 Cocos 3.8.7 横屏农场与四个底部入口，增加一条“生产原料 → 加工／钓鱼 → 新订单 → 每日奖励 → 永久升级”的经营循环。

- 风车工坊：小麦面包、农场奶酪、草莓果酱、南瓜派。原料预扣、顺序加工、完成领取，真实时间戳支持离线制作。基础两个队列位置，升级可提速并增加位置。
- 池塘钓鱼：鱼饵、等待咬钩、在提示后收杆；普通鱼和稀有金鱼进入仓库、图鉴和新订单。结果在抛竿时固定，刷新不重新抽取。初始五份鱼饵，每五分钟恢复一份至五份，也可金币购买。
- 每日小目标：收获、收蛋奶、交货、制作、钓鱼五选三。每项独立奖励，任意三项完成后领额外奖励。以北京时间自然日刷新，保存当日基线，避免旧总进度直接充当新一天进度。
- 永久建设：水渠加快新播作物；工坊缩短新任务时间并扩队列；精心照料缩短新一轮动物产出。每条三级，金币和农场星双资源升级，已经在计时的生产不追溯改期。
- 丰收图鉴：作物、蛋奶、四种商品和两种鱼共十四项；发现 4／8／12／14 种领取里程碑奖励，出售不清空已发现记录。
- 新订单：按等级逐步加入鱼类和加工商品需求，原有前三张新手订单保留。

入口：左上小按钮进入工坊、钓鱼；点击风车／池塘也可进入。底部农场手记增加“成长／今日／建设／图鉴”页签。新图标补成与原站美术协调的透明手绘图集，运行时仍为 Cocos UI。

存档继续沿用原键；新增 features.schema=1。加载旧档时只补全新产品和扩展状态，并备份原始 JSON。坏格式或未来版本扩展状态拒绝加载并保留备份。全部新功能通过纯模型测试和真实浏览器按钮流程验收后交付。
