# 晴野物语 · 0.8.0

Cocos Creator 3.8.7 + TypeScript 横屏农场，扩展至 **22种作物、27种陆地动物＋5种水产、100级、9类工厂、26份配方、70种产品、6张地图**。主农场保留三个相邻扩张区域，最终84个田位。

[本机试玩](http://localhost:7526/?v=0.8.0) · [六阶段路线](docs/expansion/v07/roadmap.md) · [内容数值](docs/expansion/v07/content.md) · [验收](docs/verification.md)

## 从 GitHub 获取工程

仓库提供 Cocos Creator 工程、TypeScript 源码、原创素材及有分发许可的第三方资源。签名材料、APK、iOS 归档和本机构建输出单独保存。

启动农场需要 `assets/resources/refart/` 中的 90 个 PNG。该目录的参考站素材尚未确认公开分发授权，保存在本机。已有本地工程可沿用该目录。新检出的工程需把有权使用的同名 PNG 放到该目录，文件名以 [RefArtData.ts](assets/scripts/RefArtData.ts) 的键为准，再用 Cocos Creator 3.8.7 打开工程并预览 `assets/scenes/Farm.scene`。字体和录音的许可见 [第三方声明](platforms/ios/ThirdPartyNotices.txt)。

## 0.8.0 单机更新

- 顶部「农场主线」开启五步章节「第一炉面包」。旧档读取既有收获、加工和订单记录。订单刷新会参考农场的库存、已解锁的材料来源及可生产的配方。
- 「旅行手册」出发后可打开「地区故事」。五个地区各有一个委托，80、90、100 级可完成专属荣誉。探索按层数切换 12 套地形配色和标志物，使用现有精灵素材。雪原冰湖新增三次定时拉线。
- 「我的小屋」和建成的木材厂可进入「家具制作台」。木板和棉布在开工时扣除，45 秒后可将成品领入家具箱。
- 「季节与自动化 → 四季比赛与日历」包含春日花艺、秋日南瓜和按北京时间月份开放的活动。生长中的南瓜可浇水、加堆肥。5 级后的暴雨可能让一块空田积水，可用 1 木板或 40 金币疏通。
- 成年猫狗可在主农场「宠物巡院」，点击场景线索找田鼠或货袋。27 种陆地动物各有独立点击音效，包含实录和原创拟音。猫抓鼠、狗找货袋和水产也有单独的声音反馈。育种可查看三代家谱，自动消耗可给每种材料保留 0、5、10 或 20 份。
- 鸡牛使用已有的帧动画，其余陆地动物各有独立的动作关键帧，点击和待机时都会播放。兔子连跳、鹅伸颈、马扬前蹄、孔雀舒展尾屏。水产有不同的游动或侧行节奏。巡院时成年宠物沿小路逐处嗅探。点击正确的线索会看到猫伏身扑向田鼠，或狗低头叼起货袋。
- 「设置 → 导入存档」选取本地 JSON，预览后确认。导入、恢复前会备份当前农场，「恢复本机备份」可找回。旧档仍使用原存档键。

Android 0.8.0 签名包与 iOS 0.8.0 工程位于 `releases/`。Android 在模拟器覆盖安装并验证，iOS 归档已编译，签名与真机验收待完成。新玩法可通过 `npm run smoke:journey` 验证。

## 本版新增

- **游戏正式名称《晴野物语》**：新封面用于加载页和开始页，网页标题与存档导出名称同步更新，关闭原 Cocos 启动标识。封面原图与生成提示词见 [美术记录](docs/expansion/v07/art.md)。
- **基因育种**：“动物伙伴→基因育种”，手选两位同族成年伙伴，选择产能、温顺或体质方向。双亲基因、谱系、代数和变异结果会保存，幼崽接回后继承；普通／稀有同族可杂交，自身、亲子和同亲兄弟姐妹不可配对。
- **自由装修**：“我的小屋”可拖动、旋转、收回家具，或先选家具再点地板摆放。支持同款多件、4种墙面和4种地板配色，6×6小屋可扩到8×8、10×10。旧六位置家具自动迁移，最多拥有40件。
- **深度探索**：森林、矿山、海滩、雪原各12层，进入目的地后从“旅行手册→分层探索”开始。每层3处路线，有采集、遗迹、断桥、幼鸟与营地事件；雪原可冰湖垂钓。带成年伙伴同行可获得加成，探索背包、体力和事件可续玩，安全返程入库，每层首次完成奖励80金币＋2星。
- **离线自动化**：10级建管理站，统一在线与最多8小时离线生产。支持自动收获补种、喂养、动物产物、水产循环，以及每厂一种配方的连续加工；小麦→面粉→面包可实际接续。所有种子、饲料、材料均从库存或金币扣除，缺料暂停。回来显示收获、支出与库存净变化，确认报告不重复发货。

详细条件与操作见 [新版玩法](docs/expansion/v07/gameplay.md)。原旅行返回提示、全部动物外出游玩、水产养殖、训练比赛与四季交货活动继续保留。

## 延续玩法

- 种子选择器4页，新增水稻、土豆、卷心菜、黄瓜、大豆、棉花、甘蔗、西瓜、葡萄、橙子、油葵、可可、咖啡、薰衣草、极光莓和黄金南瓜，逐级解锁。
- 鸡、牛、鸭、羊、猪、山羊、兔、猫、狗、马、孔雀、黄金羊、彩虹牛、独角兽各有产物。新增动物实际移动、转向、起伏和回应点击；原鸡牛完整动作帧保留。猪找松露，猫巡逻带回香草，狗增加探索奖励，马／独角兽缩短探索时间。
- “动物伙伴”可喂食、互动、治疗。饱食、心情、健康、亲密和稀有度影响下一轮效率。两只同品种成年动物亲密≥20、心情≥60，花100金币及4饲料可繁殖；育幼2分钟、成长5分钟、双亲冷却1小时。羊／牛有5%稀有变种概率，结果开始时保存。离线饥饿有下限，不会离线死亡。
- 九类工厂：磨坊、面包房、奶制品厂、果汁厂、纺织厂、糖果厂、酿造坊、木材厂、罐头厂。各厂独立队列，同厂顺序加工，基础每厂2格，升级至5格。小麦→面粉→面包，棉花→棉布→衣服，木材→木板→家具，甘蔗→糖→糖果／巧克力等使用真实材料；旧配方及活跃时间保留。
- “旅行手册”前往工匠小镇、青杉森林、蓝晶矿山、贝壳海滩、极光雪原。小镇建筑可进入对应工厂；资源地图各9个节点，耗2体力、10分钟恢复。体力上限24、每2分钟恢复1。远行耗4体力、基础30秒，奖励和倒计时保存，离线继续；海滩码头可钓鱼。
- 每20分钟换季、4分钟换天气。右上季节入口有当季目标，春花会／夏渔赛／秋丰收／冬工匠。雨、暴雨、雷雨自动浇水一次；大雪暂停咖啡、可可、西瓜、黄瓜、甘蔗。雷电送铜矿，彩虹送宝石，极光送极光莓并提前解锁种子，每天气时段只领一次；不做离线毁田。
- “我的小屋”提供7种家具，消耗金币、木板、棉布，自由摆放、旋转和刷新保存。
- 四季面板建造自动收获器（10级、400金币、5铜矿）和自动喂养器（6级、250金币、2铜矿），单独开关。未开管理站时保留前台每5秒检查；管理站开启后接入持续生产和离线结算。喂养只消耗已有饲料。
- 100级奖励册保留用户参考图的大星星、新解锁卡片及“太棒了！”按钮。每级只领一次，可补领旧等级；满级经验条保持满格。扩充高等级加工／稀有农产品订单。

## 原有操作

点成熟作物收获、点空地选种，选种后划过空地连续播种，划过成熟田地连续收获。再次点同一生长作物浇水一次，缩短20%生长时间。拖动地图、滚轮／双指／右上加减缩放；Esc关闭弹窗或取消操作。

底部农场／仓库／订单／商店保留，商店有土地、动物、装饰、农场星。原村民行走、坐凳聊天，汽车／货车行驶，交货触发货车出发。每日5选3目标、三级设施、图鉴奖励、18格花圃、普通及特别装饰继续可用。“开拓地图”3／6／10级开放草甸、果林、牧场；新区独立开垦，苹果树／蜂箱和礼篮配方保留。鸡叫、牛叫、收菜、升级音效及开关保留。

Cocos Dashboard添加本目录，用 **Creator 3.8.7** 打开 `assets/scenes/Farm.scene`。H5输出 `build/web-desktop`，通过HTTP访问。默认引擎路径 `/Volumes/mac/tools/cocos/3.8.7/CocosCreator.app/Contents/MacOS/CocosCreator`，可用 `COCOS_CREATOR` 修改；其他机器需修改 `tsconfig.check.json` 引擎声明路径。3.8.8本机导入不稳定，本版固定3.8.7。浏览器测试使用独立存档和外置盘Chromium，可用 `CHROME_PATH` 修改。

## 工程与保存

`FarmCatalog`保存新内容配置，`FarmLife`负责照料、繁殖、旅行、体力、探险、四季、家园和自动化，`LifePanels`绘制原生界面。`FarmModel`管理基本经济和迁移；`FarmFeatures`管理加工、钓鱼、每日、设施、图鉴；`FarmProgression`管理等级和农场扩张。`FarmAdvanced`、`FarmGenetics`、`FarmRoom`、`FarmExplore`、`FarmAutomation`分别管理新增存档、基因、房间、探索和离线结算；`AdvancedValidation`验证新状态，`AdvancedPanels`和`RoomPanel`绘制原生界面。场景、运动、输入、音效模块继续保留。

运行美术共202张，本版新增品牌封面，0.6版18张见 `assets/resources/nextart` 与 [记录](docs/expansion/v06/art.md)，上一版81张在 `assets/resources/lifeart`，透明图集、完整提示词、处理脚本和校验值见 [素材记录](docs/expansion/v05/art.md)。新增动物采用独立精灵加运行时运动，没有为每种新动物制作多帧逐帧动画。音效来源见 `docs/audio/CREDITS.md`。原站公开前端快照保留在 `reference-site`，不是未发布的原工程或服务端；运行不依赖原站。0.4文档保存在 `docs/history/v04`。

0.7加载旧档先保存 `-before-v07` 原始备份，再添加基因、自由房间、探索和自动化状态；旧动物、余额、库存、生产时间和已摆家具保留。管理站默认关闭，不追溯未开启前的自动产出。

存档键仍为 `sunny-meadow-farm-v1`，0.4先备份原始JSON至 `-before-v05` 再迁移，保留余额、库存、地块、动物、装饰、订单和既有生产时间。无效存档也先备份。设置可导出JSON，重置前确认并备份。

社交、交易、合作社和排行榜属于第六阶段的联网功能。当前版本提供本地 H5、Android 签名 APK 和 iOS 未签名工程。手机真机及 TapTap、微信容器仍待验收。
